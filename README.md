# 옹기종기 (Onggi) — 0단계 맥 프로토타입

친구들의 지금 상태가 **맥 바탕화면 위 캐릭터**로 보이는 메뉴바 앱.

| 상태 | 바탕화면에서 |
| --- | --- |
| 산책 중 | 화면 전체를 걸어다님. 2명 이상이면 줄지어 같이 걷고 "같이 산책 중!" |
| 공부 중 / 일하는 중 | 화면 아래 구역으로 걸어가 책상에 앉음. 여러 명이면 긴 책상에 나란히 |
| 자는 중 | 이불 덮고 Zzz. 여러 명이면 **한 이불을 같이 덮음** |
| 쉬는 중 | 컵 들고 쉬기 |

친구 캐릭터를 클릭하면 상태·경과 시간·메모를 보고 **콕 찌르기 / 화이팅 / 간식 주기**를 보낼 수 있어요. 받은 사람 캐릭터가 폴짝 뛰어요.

---

## 시작하기 (처음 한 번, 약 30분)

### 1단계. Supabase 준비 (10분)
1. [supabase.com](https://supabase.com) 가입 → **New project** (지역은 Seoul 추천, 무료 플랜).
2. **Authentication → Sign In / Providers** → **Allow anonymous sign-ins** 켜기.
   (친구들이 이메일 가입 없이 바로 쓰게 하려는 설정)
3. **SQL Editor** → `supabase/schema.sql` 내용 전체를 붙여넣고 **Run**.
4. **Project Settings → API** 에서 **Project URL** 과 **anon public** 키를 복사.

### 2단계. 키 넣기 (1분)
`Onggi/Config.swift` 를 열어 두 줄을 바꿔요.
```swift
static let supabaseURL = "https://여기에-복사한-URL"
static let supabaseAnonKey = "여기에-anon-키"
```
⚠️ **service_role** 키는 절대 넣지 마세요 (모든 데이터를 지울 수 있는 관리자 키).

### 3단계. 빌드 (Claude Code 에게 맡기기)
1. Mac App Store 에서 **Xcode** 설치 → 한 번 실행해서 추가 구성요소 설치까지 마치기.
2. Claude Code 로 이 폴더를 열고, `Claude_Code_지시문.md` 의 **지시문 1**을 붙여넣기.
3. 앱이 실행되면 메뉴바에 🐾 이 생기고, 캐릭터 만들기 창이 떠요.

### 4단계. 친구에게 배포
`Claude_Code_지시문.md` 의 **지시문 3** → `dist/Onggi.zip` + `docs/친구용_설치안내.md` + 초대 코드를 보내요.

## 구조 한눈에

```
Onggi/
  App/        앱 시작, 오버레이·설정 창 생성
  Services/   SupabaseService (서버 통신) · AppState (앱 상태)
  Overlay/    투명 창 · 움직임 계산(Simulation) · 그리기
  Character/  캐릭터 도형 · 이불 · 책상 · 말풍선
  UI/         메뉴바 창 · 캐릭터/그룹 설정 창
supabase/schema.sql   DB 설계 (테이블 5개 + 권한 + 그룹 가입 함수)
```

## DB 설계 요약

| 테이블 | 내용 | 누가 볼 수 있나 |
| --- | --- | --- |
| profiles | 닉네임, 캐릭터 종류(6), 색(6) | 나 + 같은 그룹 친구 |
| groups | 그룹 이름, 6자리 초대 코드 | 그룹 멤버 |
| group_members | 누가 어느 그룹에 (여러 그룹 가능, 그룹당 최대 10명) | 그룹 멤버 |
| statuses | 지금 상태, 한 줄 메모, 시작 시각 | 나 + 같은 그룹 친구 |
| pokes | 찌르기·응원·간식 기록 | 보낸 사람·받은 사람 |

- 그룹 만들기·가입은 `create_group`, `join_group` 함수로만 가능 (11번째 사람은 `group_full` 로 거절).
- 상태를 바꿀 때만 시작 시각이 새로 찍혀서 "2시간째"가 정확하게 유지됨 (메모만 바꾸면 그대로).
- 상태·멤버·찌르기는 실시간으로 전달되고, 혹시 끊겨도 20초마다 새로고침.
