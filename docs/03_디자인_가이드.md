# 디자인 가이드 (0단계 초안)

## 분위기
- **아늑하고 말랑한** 느낌. "작은 친구들이 옹기종기 모여 사는 내 바탕화면".
- 참고 시안: `references/mockup_v0.png` (첫 이미지 시안). 구성은 좋지만 전체가 파스텔 보라로 덮여 **유치하게** 느껴짐.
- 개선 방향:
  - 배경·UI는 **채도를 낮춘 중립색**(웜 그레이, 오프화이트), 색은 **캐릭터에만** 준다.
  - 보라는 포인트 컬러 한 곳(선택 상태, 주요 버튼)에만.
  - 손글씨 장식 문구는 마케팅 이미지에만, 앱 UI에는 쓰지 않는다.
  - 둥근 모서리, 부드러운 그림자는 유지하되 그라데이션은 최소화.

## 캐릭터 원칙
- **오리지널 캐릭터만.** 타사 캐릭터(치이카와, 리락쿠마, 가나디, 산리오, 디즈니 등)의 이름·외형·특징을 흉내 내지 않는다.
- 공통 체형: 둥근 몸통 + 큰 머리 느낌, 짧은 발, 점 눈, 볼터치, "w" 입.
- 0단계 종류(6): 고양이, 곰, 토끼, 병아리, 원숭이, 강아지 — 귀·얼굴 패치만 달라지는 구조.
- 색(6): cream, peach, mint, sky, lilac, cocoa — 각 색은 몸통색 + 진한 테두리색 한 쌍.
- **레이어 구조**(꾸미기 대비): 발 → 귀 → 몸통 → 얼굴 → (예정) 옷 → 머리 소품 → 손 소품.

## 상태별 장면

| 상태 | 혼자일 때 | 2명 이상일 때 |
| --- | --- | --- |
| 공부 | 책상 + 펼친 책 | 긴 책상에 나란히, "같이 공부 중!" |
| 일 | 책상 + 노트북 | 긴 책상에 나란히, "같이 일하는 중!" |
| 잠 | 이불 + Zzz, 눈 감기 | **한 이불을 같이 덮음**, "같이 자는 중" |
| 산책 | 화면 전체를 걸어다님 | 리더를 따라 줄지어 걸음, "같이 산책 중!" |
| 쉬기 | 컵 들고 앉아 있기 | 나란히 앉기, "같이 쉬는 중" |

## 시안에서 가져갈 화면 (1단계 이후)
- 아이폰 잠금화면·다이내믹 아일랜드: "공부 중 · 1시간 24분째"
- 홈 화면 위젯: 그룹 장면(같이 자는 모습), 공부 시간, "지금은 산책 중!"
- 앱 안의 "우리 방": 캐릭터들이 사는 방, 하단 탭(홈·약속·앨범·설정)
- 캐릭터 꾸미기: 기본·액세서리·의상·소품 탭, 색 팔레트
