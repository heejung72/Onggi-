# 옹기종기 설치 방법 (친구용, 2분)

아직 앱스토어에 올리기 전 테스트 버전이라, 처음 한 번만 맥이 막아요. 아래 순서대로 하면 열려요.

1. 받은 **Onggi.zip** 을 더블클릭해서 압축을 풀어요.
2. 나온 **Onggi** 앱을 **응용 프로그램(Applications)** 폴더로 옮겨요.
3. Onggi 을 더블클릭 → "열 수 없습니다" 같은 경고가 뜨면 **완료(Done)** 를 눌러요.
4. **시스템 설정 → 개인정보 보호 및 보안** 으로 가서 맨 아래까지 내려요.
5. "Onggi 이(가) 차단되었습니다" 옆의 **그래도 열기(Open Anyway)** 를 누르고, 비밀번호를 입력해요.
6. 화면 위 메뉴바에 🐾 발바닥 아이콘이 생기면 성공!

## 처음 설정
1. 캐릭터와 닉네임을 고르고 **캐릭터 만들기**.
2. **초대 코드로 가입** 칸에 받은 6자리 코드를 넣고 **가입**.
3. 바탕화면에 친구들 캐릭터가 나타나요. 메뉴바 🐾 에서 내 상태(공부·일·잠·산책·쉬기)를 바꿔 보세요.

## 사용 팁
- 친구 캐릭터를 클릭하면 상태와 "콕 찌르기" 버튼이 나와요.
- 캐릭터가 창에 가려서 안 보이면: 메뉴바 🐾 → **모든 창 위에 표시** 켜기.
- 잠깐 숨기고 싶으면: 메뉴바 🐾 → **바탕화면에 캐릭터 보이기** 끄기.
