# 옹기종기 (Onggi) 기획서 요약

> 원본 기획서(편집 가능): https://claude.ai/artifact/HCToVFQfWHw1eAuhV2y6NX
> 마지막 정리: 2026-10-31

## 한 줄 정의
**친구들이 지금 뭐 하는지, 내 화면 위의 작은 캐릭터들이 보여주는 앱.**
사진이나 글을 올리지 않아도 각자의 캐릭터가 상태(공부·일·잠·산책)에 맞춰 바뀌고, 친구들과 한 공간에서 함께 움직인다.

- **핵심 감정:** 연락하지 않아도 "같이 있다"는 느낌 (ambient presence)
- **차별점:** 상태 공유를 사진·텍스트 대신 **캐릭터 애니메이션**으로. 캐릭터끼리 상호작용한다 (같이 자기, 같이 걷기).
- **보이는 곳:** 앱 안이 아니라 **맥 바탕화면 위**와 **아이폰 홈 화면 위젯**
- **설계 원칙:** 기록 앱이 아니라 "곁에 있는" 앱. 피드·좋아요 같은 SNS 문법은 최소화한다.

## 타깃 사용자

| 사용자 | 상황 | 얻는 것 |
| --- | --- | --- |
| 친한 친구 그룹 (3~8명, 20대) — 1차 | 학교·회사·자취로 흩어짐 | 연락 없이도 서로의 하루가 보임, 놀 약속 잡기 |
| 커플 | 썸원·비트윈 사용층 | 둘만의 방, 같이 자는 장면 |
| 공부 메이트 (확장) | 열품타·캠스터디 사용층 | 캐릭터가 같이 공부 = 가벼운 동기부여 |
| 팀플·소규모 팀 (확장) | 슬랙 상태 표시 사용층 | 팀원이 집중 중인지 보이는 현황판 |

출발점은 "일반 대중"이 아니라 **"나와 내 친구 5명이 매일 켜두는 앱"**.

## 레퍼런스에서 배운 것
- **썸원, 셋로그, Locket:** 위젯으로 홈 화면에 상시 노출 → 우리도 위젯이 핵심 채널.
- **BeReal:** 다 같이 공유하는 의식 → 주간 리포트·공부 타이머 같은 의식을 만든다.
- **열품타:** 그룹 공부 시간 → 공부방 모드로 확장.
- **Zenly (종료), Bondee (이탈):** 가장 닮은 서비스. **신기함만으로는 유지 안 됨** → 매일 돌아올 이유를 처음부터 설계.
- **데스크톱 펫:** 바탕화면을 돌아다니는 캐릭터 → 우리는 여기에 "소셜"을 더한다.

## 핵심 기능
1. **내 캐릭터:** 오리지널 캐릭터 고르기 + 로블록스처럼 부위별 꾸미기. 사진 기반 생성은 2단계 이후.
2. **상태:** 공부·일·잠·산책·쉬기(+ 밥·이동·게임·방해금지 확장). 한 줄 메모, "2시간째" 경과 시간.
3. **함께 있는 장면 (가장 중요):** 같은 상태끼리 모인다 (한 이불·긴 책상·줄지어 산책). 찌르기·응원·간식 주기.
4. **일정과 추억:** 놀 약속 잡기(날짜 투표), 추억 앨범, 주간 리포트 공유 카드.

## 로드맵 (관문을 넘으면 다음 단계)

| 단계 | 내용 | 다음으로 가는 관문 |
| --- | --- | --- |
| **0. 프로토타입 (지금)** | 맥 바탕화면 캐릭터, 상태 5개, 친구 실시간 동기화, 찌르기 | 친구 5명이 1주일간 매일 켜두는가? |
| 1. MVP | 아이폰 앱 + 홈 화면 위젯, 상태 8~10개, 함께 장면 추가, 집중 모드 연동, TestFlight | 4주 후에도 그룹 절반 이상이 매일 쓰는가? |
| 2. 함께하기 | 놀 약속, 추억 앨범, 주간 리포트, 앱스토어 출시 | 친구 그룹 밖 사람들이 스스로 가입하는가? |
| 3. 확장·수익화 | 꾸미기 상점, 장면 테마, 선물하기, 공부방·팀플방, 구독, 안드로이드용 웹 뷰어 | — |

## 수익 모델 (3단계)
- 꾸미기 아이템 (핵심), 그룹 공유 장면 테마, 선물하기, 프리미엄 구독, B2B(스터디·팀), 캐릭터 IP.
- 광고는 넣지 않는다 ("아늑한 공간" 감성을 깨므로).
- 수익보다 먼저 증명할 숫자: **친구 그룹의 몇 %가 4주 후에도 매일 위젯을 보는가.**

## 주요 리스크
- **유지율:** 매일 돌아올 이유가 필수.
- **아트 리소스:** 캐릭터 × 상태 × 함께 장면 조합이 폭발 → 레이어 조립 구조로 설계.
- **네트워크 효과:** 친구가 없으면 빈 방 → 초대 링크, 혼자서도 즐거운 공부 타이머.
- **아이폰 전용:** 안드로이드 친구 배제 → 장기적으로 웹 뷰어.
- **프라이버시:** 수면 시간 등이 노출됨 → 친구별 공개 범위, 상태 숨기기.
