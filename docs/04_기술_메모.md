# 기술 메모

## 플랫폼별 제약
| 화면 | 가능한 것 | 제약 |
| --- | --- | --- |
| 맥 바탕화면 오버레이 | 투명 창 위에서 캐릭터가 자유롭게 움직임 | 배터리·CPU 관리, 클릭 통과 처리 |
| 맥 메뉴바 | 상태 빠른 변경 | 공간 작음 |
| 아이폰 홈 화면 위젯 | 장면 이미지, 버튼으로 상태 변경 | **계속 움직이는 애니메이션 불가**, 갱신 횟수 제한 → "볼 때마다 장면이 바뀌어 있는 액자"로 설계 |
| 아이폰 잠금화면·다이내믹 아일랜드 | 진행 중 활동 실시간 표시 (Live Activity) | 진행 중인 활동에만 적합 → 공부 타이머 |
| 아이폰 앱 | 풀 애니메이션, 약속·앨범·꾸미기 | 앱을 열어야 보임 |

- 애플 생태계만 지원하므로 SwiftUI 하나로 iOS + macOS. 앱스토어 "유니버설 구매"로 한 번 받으면 양쪽에서 사용.
- 상태 자동 입력 후보: 아이폰 집중 모드, 단축어 자동화, 걷기 감지, 맥 잠금 감지, 시간 기반 추정. **자동 감지는 항상 사용자가 켜는 것(옵트인)**, 정확한 위치는 공유하지 않는다.

## Supabase 설계 요약 (`supabase/schema.sql`)
- 테이블: `profiles`, `groups`, `group_members`, `statuses`, `pokes`
- 권한(RLS): 같은 그룹 친구끼리만 서로의 프로필·상태가 보임. 그룹 생성·가입은 `create_group`, `join_group` 함수로만.
- `statuses.started_at`: 상태가 바뀔 때만 새로 찍힘 (메모만 바꾸면 경과 시간 유지).
- 실시간: `statuses`, `pokes`, `group_members` 를 구독. 앱은 변경 신호를 받으면 다시 조회 (+ 20초마다 새로고침).
- 2026-10-31 로컬 Postgres로 검증: 10명 제한, 비멤버 차단, started_at 동작, 찌르기 권한 모두 통과.
- 무료 플랜은 오래 접속이 없으면 프로젝트가 일시정지됨 → 대시보드에서 Restore.
- 앱에는 **공개 키(publishable / anon)만**. secret / service_role 키는 절대 코드에 넣지 않는다.
- 스키마를 바꿀 때는 `schema.sql` 을 고치고, 이미 적용된 DB용 **변경 SQL을 별도 파일**(`supabase/migrations/날짜_내용.sql`)로 만든다.

- 앱스토어 단계에서 바꿀 것: 샌드박스 ON + 네트워크 권한, 세션 저장소를 키체인으로, 애플 로그인, 정식 서명.

## 0단계 구현 메모
- 오버레이: 테두리 없는 투명 `NSPanel`. 기본은 바탕화면 아이콘 바로 위(다른 창 아래), 메뉴바에서 "모든 창 위" 전환.
- 클릭 통과: 초당 30번 마우스 위치를 보고 캐릭터·카드 위에서만 `ignoresMouseEvents = false`.
- 움직임: `Simulation` 이 초당 30번 위치 계산. 고정 상태는 화면 아래 상태별 구역으로 이동, 산책은 리더를 따라 줄지어 걷기.
- 캐릭터는 이미지 없이 SwiftUI 도형으로 그림 (아트 투자 전 반응 확인용).
- 메인 모니터만 지원 (다중 모니터는 다음 단계 지시문 B).
